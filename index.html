Renderers

Nether Launcher provides different rendering options for different devices and Minecraft versions.

LTW

Large Thin Wrapper is designed for modern Minecraft versions using OpenGL ES.

GL4ES

GL4ES provides compatibility for older Minecraft versions and OpenGL requirements.

ANGLE

ANGLE can provide an alternative graphics backend on supported devices.
