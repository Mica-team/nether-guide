## Getting Started

**Nether Launcher** is a Minecraft: Java Edition launcher for Android, based on technologies and ideas from projects such as **PojavLauncher** and **Mojo Launcher**.

You may notice similarities between Nether Launcher and other Minecraft launchers. However, Nether Launcher has its own features, interface, improvements, and development direction.

> 💡 **Tip:** If you're new to Nether Launcher, start by selecting a Minecraft version and configuring your Java runtime and RAM allocation.

---

## Minecraft Versions

Nether Launcher supports a wide range of **Minecraft: Java Edition versions**, including many older versions.

Minecraft continues to receive new versions and updates. Nether Launcher is designed to work with the launcher and version-management systems needed to support Minecraft versions as they become available.

> ⚠️ **Note:** Compatibility can vary depending on the Minecraft version, Android device, Java runtime, renderer, and installed mods.

---

## Java Runtimes

Java runtimes provide the Java environment required to run Minecraft: Java Edition.

Different Minecraft versions may require different Java versions. **Nether Launcher automatically selects the most appropriate installed Java runtime for the Minecraft version you're launching.**

This means you usually don't need to manually choose a Java runtime.

> 💡 **Tip:** If you experience a Java-related crash or launch problem, check which runtime is installed and selected for your Minecraft version.

---

## RAM Allocation

RAM allocation determines how much memory Minecraft can use.

Giving Minecraft more RAM does **not always mean better performance**. The ideal amount depends on your device, Minecraft version, mods, and modpacks.

> 💡 **Tip:** Leave enough RAM available for Android and Nether Launcher itself. Allocating nearly all of your device's RAM can actually make performance worse.

---

## Renderers

A renderer controls how Minecraft's graphics are translated to your device's graphics hardware.

Nether Launcher provides different renderer options for different Minecraft versions and devices.

The best renderer can depend on your GPU, Android version, Minecraft version, and installed mods.

> 💡 **Tip:** If Minecraft crashes while loading graphics or shows graphical problems, trying another compatible renderer may help.

---

## Installing Mods

Mods can add new features, improve performance, change gameplay, or completely transform Minecraft.

Before installing a mod, make sure that:

1. The mod supports your Minecraft version.
2. The mod supports your mod loader.
3. Any required dependencies are installed.
4. Your renderer and device are compatible with the mod.

> ⚠️ **Important:** Installing incompatible mods can cause Minecraft to crash.

---

## Installing Modpacks

Nether Launcher includes a dedicated **modpack system** that allows you to find and download supported modpacks without manually visiting external modpack websites.

You can download a modpack directly through the built-in modpack system with just a few steps.

### What modpack services do we use?

Nether Launcher uses **Modrinth** and **CurseForge** as sources for modpack information and discovery.

Our modpack search system is still being improved. We plan to make it faster, more accurate, and easier to use in future updates.

## Performance

Performance can vary significantly between devices and Minecraft versions.

For the best experience:

- Use an appropriate renderer.
- Avoid allocating too much RAM.
- Use performance mods when compatible.
- Keep your mod list organized.
- Avoid unnecessary background applications.
- Let Nether Launcher automatically select the appropriate Java runtime.

More performance recommendations will be added to this guide as Nether Launcher develops.

## Troubleshooting

Having trouble launching Minecraft?

Start by checking:

1. Your Minecraft version.
2. Your selected Java runtime.
3. Your RAM allocation.
4. Your renderer.
5. Your installed mods and mod loader.
6. The Minecraft crash log or launcher log.

If you still need help, visit our **[Discord server](https://discord.gg/4V4bjdgAFg)** and ask for assistance.

When asking for help, providing the crash log is usually much more useful than simply saying that Minecraft crashed.

## Frequently Asked Questions

### Can Nether Launcher run older Minecraft versions?

Yes. Nether Launcher is designed to support a wide range of Minecraft: Java Edition versions.

### Can I install mods?

Yes. Mods can be installed when they are compatible with your Minecraft version and mod loader.

### Can I install modpacks?

Yes. Nether Launcher has a built-in modpack system using Modrinth and CurseForge as sources.

### Why does Minecraft crash after installing a mod?

The mod may be incompatible with your Minecraft version, mod loader, Java runtime, renderer, or another installed mod.

### Where can I get help?

You can get help from the **[Nether Launcher Discord server](https://discord.gg/4V4bjdgAFg)**.
